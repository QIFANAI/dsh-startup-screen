# 素材目录说明

本目录的 9 段音频素材**随仓库与官方 Release 完整发布**，安装后即是完整观感。
素材缺失或解码失败时插件仍会自动降级，不会中断启动：

- 台词缺失 → 回落到浏览器 TTS 念白
- 界面音效缺失 → 回落到 WebAudio 合成音
- BGM 缺失 → 静音，不报错

| 文件名 | 用途 | 说明 |
|---|---|---|
| `line-1.mp3` | 需要访问许可 | 真声台词 |
| `line-2.mp3` | 身份资料确认 | 真声台词 |
| `line-3.mp3` | 接收访问需求 | 真声台词 |
| `line-4.mp3` | 开始读取权限 | 真声台词 |
| `line-5.mp3` | 读取完毕 · 核验通过 | 真声台词 |
| `line-6.mp3` | 欢迎「身份名称」访问 | 终幕欢迎语 |
| `sfx-tick.mp3` | 单声「哒」 | 界面音效 |
| `sfx-ticks-run.mp3` | 连击「哒哒哒…」 | 界面音效 |
| `bgm.mp3` | 背景音乐 | *In Cyberpunk* / Alex Chernykh，循环播放，揭幕时淡出 |

素材规格：MP3，采样率 44.1 kHz 或 48 kHz；`bgm.mp3` 已归一化到 −18 dBFS 活跃 RMS。
