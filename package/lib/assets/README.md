# 素材目录说明

仓库**不附带**受版权保护的影音素材（原因见根目录 `THIRD-PARTY-NOTICES.md`）。
插件在素材缺失时会自动降级，因此空目录也能正常播放动画：

> 例外：`line-6.mp3`（终幕欢迎语）是作者本人录制，已随仓库提供。

- 台词缺失 → 回落到浏览器 TTS 念白
- 界面音效缺失 → 回落到 WebAudio 合成音
- BGM 缺失 → 静音，不报错

## 想用自己的素材

把文件按下面的名字放进本目录即可（MP3，采样率 44.1kHz 或 48kHz）：

| 文件名 | 用途 |
|---|---|
| `line-1.mp3` | 需要访问许可 |
| `line-2.mp3` | 身份资料确认 |
| `line-3.mp3` | 接收访问需求 |
| `line-4.mp3` | 开始读取权限 |
| `line-5.mp3` | 读取完毕 · 核验通过 |
| `line-6.mp3` | 欢迎「身份名称」访问 |
| `sfx-tick.mp3` | 单声“哒” |
| `sfx-ticks-run.mp3` | 连击“哒哒哒…” |
| `bgm.mp3` | 背景音乐 |

素材必须是你自己录制或已获得授权的内容。放入后重启桌面端生效。
