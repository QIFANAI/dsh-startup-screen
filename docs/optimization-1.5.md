# 1.5.0 视觉重构方案（候选）

## 一、为什么现在"廉价"
1. **单平面**：底板、面板、文字、准星都在同一 Z 平面，没有前景/中景/背景，缺少空间纵深。
2. **光没有来源**：只有一块柔光渐晕，没有方向性主光、接触阴影和环境遮蔽，面板像贴纸。
3. **材质停在"噪点"**：拉丝振幅 ±0.05、静态颗粒，近看有、远看无；没有随镜头变化的镜面高光。
4. **字体层级单一**：主字 40px/400、副字 13px，字重、字号、明度差不够；没有"标题—数据—注释"三级字阶。
5. **动效同质**：大量 opacity + translate，时长 300–600ms，曲线相近；缺"蓄力—释放—余震"的机械节奏。
6. **逻辑感弱**：1.4.0 有真数据，但视觉上只是两行小字；数据没有参与构图和动效。

## 二、改造方向：光学档案仪器
把画面当成一台正在启动的光学仪器，而不是一张 HUD 线框图。

### A. 空间（先解决"平"）
- 新增大气层：右上暖光、左下冷光，缓慢漂移。
- 新增体积光：两道极淡的斜向光柱，随镜头轻移。
- 新增地面反射：底部一条极弱的地平线与反光，给底板"站立"的物理感。
- 背景档案面板分远/中/近三层，分别加 2.5px / 1px / 0.3px 模糊与不同阴影。
- 镜头层：底板 1.035× 缓慢推进，面板 1.06× 视差，中心区轻微上浮。

### B. 材质（解决"贴纸感"）
- 底板加内倒角、顶部环境光、底部压暗、边缘 1px 高光。
- 档案面板加闭合倒角、顶部高光、接触阴影、内阴影。
- 机框加刻度尺与四角实体定位角，形成"加工件"而不是"细线框"。
- 准星外环从 6px 实心白环收成 1.6px 精密环，内环 1px；新增数据环与彗星扫描弧。

### C. 字体（解决"没有主体"）
- 主标题：clamp(46px, 4.4vw, 68px)，字距 0.15em，加轻微浮雕阴影。
- 英文副标题：12px / 0.52em，颜色降一档，形成"标题—注释"层级。
- 逐字入场：blur 2px + scale 0.96 + translateY 0.16em，420–520ms 对焦，保留等宽替身不抖动。
- 终幕：WELCOME 加字距与浮雕，黑底框加内高光和外投影。

### D. 动效（解决"匀速淡入"）
- 统一四种曲线：机械咬合、光学对焦、弹簧回弹、故障收敛。
- 准星：外环 18s、内环 11s、彗星 6.8s 三层不同速度；锁定时 1.2s 冲击波。
- 转场：洗白改为径向过曝 + 边缘压暗，不再整屏纯白。
- 终幕：光晕峰值闪白从 0.72 降到 0.32，峰值 1.2s 后撤掉，避免浅色主题文字被洗没。

### E. 逻辑（解决"装饰"）
- 右侧新增 `SELF-CHECK / LIVE` 清单：PROFILE / BUNDLES / MODEL / SANDBOX / SESSIONS。
- 每一步点亮一项，值来自 Host 的 `collectFacts()`；取不到显示 `—`。
- 准星数据环按 `bundleCount` 点亮对应格数。
- 十六进制瀑布由 `facts.hash + model + bundleCount` 派生，不再是纯随机。
